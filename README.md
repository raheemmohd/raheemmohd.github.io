# Mohammed Abdul Raheem — Cybersecurity Portfolio

A modern cybersecurity portfolio designed for GitHub Pages.

## Sections
- Cybersecurity hero / personal branding
- About
- SOC, VAPT, network security and automation skills
- Featured security projects
- Hands-on security workflow
- Contact links

## Customize before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html`.
2. Replace the LinkedIn URL with your real LinkedIn profile.
3. Add your `resume.pdf` to the root folder.
4. Update GitHub project links to your individual repositories.
5. Commit and push to GitHub.
6. Enable **Settings → Pages → Deploy from branch**.

## Recommended repository name
`raheemmohd.github.io`

The site is static HTML/CSS/JS and works directly with GitHub Pages.
